# Optional Copilot SDK proof

Agentflow has an optional, import-lazy observer for the GitHub Copilot SDK. Install it with `pip install 'saintdle-agentflow[copilot]'`. The observer records per-call usage events and actual model names, rejects missing or mismatched usage, resume gaps, tool activity, and incomplete inventories. It does not infer actual model identity from a selected-model field.

The runner requires a controller-signed accepted-review attestation before it can reserve the protected first attempt or request a provider credential. The owned controller issues it through `issue_copilot_review_attestation`, which requires the canonical resume proof, exact active claim, accepted judgements from two distinct reviewers, and their distinct artifact digests. It rereads the claim and lease under the controller fence, binds the current source commit/module hashes and preflight digest, and writes a write-once `0600` file outside the workspace. This is the controller's explicit disposition; review packets themselves are not provider-signed. The proof runner only verifies the attestation. Caller flags and imported Beads or JSON metadata cannot grant approval.

Preparation reserves exactly one 180-second attempt with zero retries in the existing authenticated execution ledger. Its deadline and claim are rechecked before provider startup, which is capped by that original deadline. Verification-only mode authenticates the manifest and protected head/rows without prompting, reserving, writing, or starting the SDK. Controller storage and immutable manifests live outside the worker workspace. Persistent admission remains false.

When an authorized proof is eventually run, provider credentials must arrive through a no-echo terminal prompt or a protected inherited pipe/socket/tty file descriptor. The credential is never accepted in chat, environment variables, argv, or files, and is not included in reports or logs. Do not run the provider proof without the separate user credential gate.

Hermetic fixtures exercise signed-manifest, lease, claim, key-origin, budget, tamper, rollback, source-drift, model-mismatch, fallback, resume-gap, crash-gap, and path-alias rejection. They are not live SDK evidence. The current source changes do not establish a live runtime boundary, provider-signed model identity, fallback behavior, or resume behavior. Until an accepted controller attestation and those live proofs exist, keep persistent admission disabled.

The observer follows GitHub's pinned [Python SDK reference](https://github.com/github/copilot-sdk/blob/v1.0.17/python/README.md), [per-call usage and billing reference](https://github.com/github/copilot-sdk/blob/v1.0.17/docs/features/usage-and-billing.md), [streaming event schema](https://github.com/github/copilot-sdk/blob/v1.0.17/docs/features/streaming-events.md), and [SDK v1.0.17 release](https://github.com/github/copilot-sdk/releases/tag/v1.0.17).
