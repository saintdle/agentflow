# Governance

Agentflow is maintained in the `saintdle` GitHub organization. Maintainers are
responsible for project direction, reviews, releases, security response, and
community moderation.

## Decision making

Routine decisions are made through issues and reviewed pull requests. The
maintainers seek evidence and rough consensus, but consensus is not required.
Maintainers have final responsibility for decisions affecting security,
compatibility, scope, and long-term maintenance.

Material changes to public commands, configuration schemas, trust boundaries,
or supported platforms should begin with an issue that records:

- the problem and intended users;
- alternatives and compatibility effects;
- security and migration implications;
- observable acceptance evidence.

## Maintainer responsibilities

Maintainers should:

- disclose conflicts of interest;
- avoid reviewing their own security-sensitive change as the sole approver;
- protect embargoed vulnerability information;
- apply the Code of Conduct consistently;
- keep releases reproducible and project history accurate;
- document material deprecations and governance changes.

Maintainer access is granted or removed by existing organization owners based
on sustained contribution, sound judgment, availability, and security needs.

## Project changes

This document may be updated through the normal pull-request process. Changes
to ownership, licensing, or the project's legal home require approval from an
authorized organization owner.
