# Support

Agentflow `0.0.2` is a community-supported development/testing preview. There is no warranty,
paid support commitment, or guaranteed response time.

Before requesting help:

```sh
agentflow --version
agentflow doctor
agentflow skills doctor
```

Search existing GitHub issues, then open:

- a bug report for reproducible incorrect behavior;
- a feature request for a new capability or compatibility change;
- a documentation issue for unclear or inaccurate guidance.

Share the smallest reproducible example and redacted diagnostic output. Never
post credentials, private paths, provider transcripts, proprietary prompts,
customer data, or account and billing information.

Questions about provider authentication, subscriptions, quotas, or service
availability belong with that provider. Beads and Herdr issues that reproduce
without Agentflow belong in their upstream projects.

Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
